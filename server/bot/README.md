# Lost & Found - Telegram Bot

## 🤖 Описание

Telegram бот для сервиса Lost & Found, полностью интегрированный с существующим сайтом и базой данных.

### Возможности бота:
- **Мультиязычность**: Русский, Узбекский, Английский
- **Регистрация/Авторизация**: Связка с существующим аккаунтом или создание нового через Telegram
- **Создание объявлений**: Пошаговое создание (тип → категория → название → описание → место → телефон → фото)
- **Просмотр объявлений**: Последние объявления, мои объявления, поиск
- **Управление статусами**: Активно / Решено / Закрыто
- **Комментарии**: Добавление и просмотр комментариев к объявлениям
- **Уведомления**: Получение уведомлений о новых комментариях и событиях
- **Профиль**: Просмотр данных пользователя

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта (скопируйте из `.env.example`):

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Database Configuration
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=lost_and_found
DB_PORT=3306

# JWT Secret
JWT_SECRET=your_super_secret_key_change_this

# Telegram Bot (обязательно!)
BOT_TOKEN=your_telegram_bot_token_here
API_URL=http://localhost:5000/api
UPLOADS_DIR=./uploads

# Server
PORT=5000
```

### 3. Получение токена бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env` в переменную `BOT_TOKEN`

Ваш бот: [@LostFoundAgentBot](https://t.me/LostFoundAgentBot)

### 4. Настройка базы данных

```bash
npm run db:migrate
```

Или вручную:
```bash
mysql -u root -p lost_and_found < server/script.sql
```

### 5. Запуск

**Запуск всего проекта (фронтенд + сервер + бот):**
```bash
npm run start:full
```

**Запуск только бота (сервер должен быть запущен):**
```bash
npm run bot
```

**Запуск бота в режиме разработки (с авто-перезагрузкой):**
```bash
npm run bot:dev
```

**Запуск сервера и фронтенда (без бота):**
```bash
npm run start
```

## 🔄 Интеграция с сайтом

Бот использует **ту же базу данных** и **тот же API**, что и сайт:
- Пользователи, зарегистрированные на сайте, могут войти в бот через `/start`
- Объявления, созданные в боте, появляются на сайте мгновенно
- Комментарии и уведомления синхронизированы между сайтом и ботом
- Telegram ID привязывается к существующему аккаунту

## 🛠 Технологии

- **node-telegram-bot-api** — Telegram Bot API
- **axios** — HTTP клиент для запросов к API
- **form-data** — Отправка фото на сервер
- **MySQL2** — Та же база данных, что и у сайта

---

## ⚠️ Важно

1. Перед запуском бота **обязательно** должен быть запущен сервер (`npm run server`)
2. Убедитесь, что папка `uploads/` существует и доступна для записи
3. Токен бота храните в секрете, не публикуйте в репозитории
4. Для работы с фото бот скачивает изображения во временную папку — убедитесь, что у процесса есть права на запись
